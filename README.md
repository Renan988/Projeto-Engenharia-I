## Tecnologias
| Tecnologia | Área de Responsabilidade | Descrição do Papel no Projeto |
| :--- | :--- | :--- |
| **TypeScript** | Front-end / Desenvolvimento Cliente | Garante tipagem estática e maior segurança ao código da interface da aplicação. |
| **Django** | Back-end / Regras de Negócio | Atua como a API principal, gerenciando a lógica do servidor, rotas complexas e integrações. |
| **Supabase** | Banco de Dados / Autenticação / BaaS | Fornece o banco de dados PostgreSQL, gerenciamento de usuários e armazenamento de arquivos. |
